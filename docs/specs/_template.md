## 9. 非機能

- **アクセシビリティ**: キーボード操作、フォーカス表示、`prefers-reduced-motion`

- **セキュリティ / プライバシー**: 外部送信の有無、保持する個人情報、第三者スクリプトの有無
- **コスト**: 従量課金が発生するか。するなら上限とアラート
