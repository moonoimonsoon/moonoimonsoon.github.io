# 001. ハブサイト（moonoimonsoon.github.io トップ）

- **Status**: Shipped
- **更新日**: 2026-08-03
- **対象**: `index.html`

> 既に動いているものを、後から仕様書に起こしたもの（リバース記述）。
> 以降の変更は、コードより先にこのファイルを直す。

## 1. 目的

タイ語の読みを学ぶ人が、Moonoi Monsoon の全アプリに1画面からたどり着けるようにする。
インストール不要・登録不要で、リンクを踏めばすぐ遊べる状態を保つ。

## 2. スコープ

**やること**
- 公開中の Web アプリの一覧表示と外部リンク
- 言語（EN / JP / TH）による絞り込み
- ダウンロード物（壁紙）とレッスン告知の掲示
- Instagram・ハブサイトへの導線

**やらないこと**
- アプリ本体の機能をこのページに実装すること（各アプリは別リポジトリ）
- ユーザー登録、フォーム、問い合わせ受付
- アクセス解析、広告、第三者スクリプトの読み込み
- ビルド工程の導入（単一 HTML を維持する）

## 3. 用語定義

| 用語 | 定義 |
|---|---|
| アプリカード | 1アプリを表す `.app` 要素。アイコン・タイトル・説明・タグ・矢印で構成 |
| 言語タグ | カードが属する言語。`data-lang="en" \| "ja" \| "th"` |
| soon カード | まだ公開していない枠を示す `.app.soon`。リンクなし |
| lesson カード | 提供時期未定のレッスン枠 `.app.lesson`。リンクなし |

## 4. 入力と出力

- **入力**: ユーザーの言語フィルタ操作のみ
- **出力**: アプリ一覧の表示・非表示
- **保存**: **しない。** localStorage / Cookie / サーバー送信のいずれも使わない。フィルタ状態はリロードで初期化される（仕様）

## 5. 画面と挙動

単一ページ。セクションは上から Hero → Web apps → Downloads → Lessons → Footer。

| 状態 | 表示 | 操作 | 次の状態 |
|---|---|---|---|
| 初期 | 全カード表示、`All` が `aria-pressed="true"` | 言語ボタンを押す | 絞り込み |
| 絞り込み（該当あり） | 該当 `data-lang` のカードのみ | 別の言語ボタン | 絞り込み |
| 絞り込み（該当なし） | カード0件＋空メッセージ | `All` を押す | 初期 |

## 6. 判定ロジック / ルール

### 言語フィルタ

| 条件 | 結果 |
|---|---|
| `filter === "all"` | `#webApps .app` を全件表示 |
| `filter === card.dataset.lang` | そのカードを表示 |
| 上記以外 | `hidden` 属性を付与して非表示 |
| 表示件数が 0 | `#emptyNote`（"No apps in this language yet."）を表示 |
| 表示件数が 1 以上 | `#emptyNote` を隠す |

**注**: soon カードは `data-lang` を持たない。したがって `All` 以外では非表示になる。これは意図した挙動。

### PWA（ホーム画面に追加）時のリンク

| 条件 | 結果 |
|---|---|
| standalone 表示モードでない | 何もしない（通常のリンク挙動） |
| standalone かつ `href` が `#` 始まり | 何もしない（ページ内アンカー） |
| standalone かつ通常リンク | `preventDefault()` して `window.location.href` で直接遷移 |

目的は、standalone 時にブラウザが出す「このリンクを開きますか？」ダイアログの抑制。
副作用として `target="_blank"` も同一ウィンドウ遷移になる（現状は許容）。

## 7. エッジケース

- **TH のアプリが0件** → 空メッセージが出る。これが正しい状態
- **`prefers-reduced-motion: reduce`** → 火の粉アニメーションを生成せず、全 transition / animation を無効化
- **Google Fonts が読めない** → `system-ui, sans-serif` にフォールバック。レイアウトは崩れない
- **JS が無効** → 全カードが表示されたまま。リンクは機能する（フィルタだけが効かない）

## 8. 受け入れ基準

| # | 前提 | 操作 | 期待結果 |
|---|---|---|---|
| 1 | 初期表示 | — | 公開中アプリ4件＋soonカードが見える |
| 2 | 初期表示 | `JP` を押す | 日本語カードのみ表示、`JP` が押下状態 |
| 3 | 初期表示 | `TH` を押す | カード0件、空メッセージ表示 |
| 4 | 絞り込み中 | `All` を押す | 全件に戻る |
| 5 | 任意 | Tab キーのみで操作 | 全リンク・全ボタンに到達でき、フォーカス枠が見える |
| 6 | 幅375px | 表示 | 横スクロールが発生しない |
| 7 | リデュースモーション有効 | 表示 | 火の粉が出ず、揺れ・遷移もない |
| 8 | 各カード | クリック | 対応するアプリが開く（404にならない） |

## 9. 非機能

- **アクセシビリティ**: `:focus-visible` アウトライン、フィルタの `aria-pressed`、装飾 SVG の `aria-hidden="true"`、ソーシャルリンクの `aria-label`
- **表示**: `max-width:680px` の1カラム。`overflow-x:hidden`
- **セキュリティ / プライバシー**: 外部送信なし。Cookie なし。外部リソースは Google Fonts のみ。外部リンクは `rel="noopener noreferrer"`
- **コスト**: GitHub Pages のみ。従量課金なし

## 10. 検証方法

自動テストなし。push 前に手で確認する。

1. ローカルで `index.html` をブラウザで開き、受け入れ基準 1〜7 を上から実施
2. DevTools のデバイスモードで 375px 幅を確認
3. OS のモーション低減設定を有効にして再読み込み
4. 全リンクを1回ずつ踏んで 404 がないことを確認（受け入れ基準 8）
5. `CLAUDE.md` §5 のセキュリティレビュー・クロスレビューを実施
